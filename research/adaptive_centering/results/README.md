# Result provenance

[`source-faithful/`](source-faithful/) contains the 133-row, 20-basis,
10,000-draw case-study results for the noncentered pilot, selected-partial
refit and online adaptive-centering fit. It includes both gradient-cost
counters, diagnostics, coordinate selections, source-equivalence checks,
gradient and loss-frame audits, and exact code/dependency provenance.

The corresponding figures are in `docs/src/assets/adaptive-hsgp/`.
Reproduction and validation commands are in the [parent README](../README.md).
