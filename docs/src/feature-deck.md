# BRM future-capability deck

The collaborator deck **Beyond feature parity** compares the future capability
enabled by brms and BayesianRegressionModels.jl. It distinguishes demonstrated
behavior, architecture-enabled engineering paths, and open research questions;
the visible footer separately records backend coverage.

- [Open the self-contained RevealJS deck](decks/brm-futures.html)
- [Download the landscape PDF](decks/brm-futures.pdf)
- [Inspect the deck source and references](https://github.com/nsiccha/BayesianRegressionModels.jl/tree/ns/devibe/docs/presentations/brm-futures)

The main talk ends explicitly before a six-slide collaborator appendix covering
current backend parity, shared preparation, generated backend structure,
extension seams, known gaps, and the contributor/reproduction path.

Prospective guests and cited authors have not reviewed or endorsed the deck.
